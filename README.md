# SoGlam UI/UX Prototype

A complete responsive front-end UI/UX prototype based on the supplied SoGlam requirements and real uploaded brand/product photography.

## Included views
- Homepage with cinematic gold-emergence hero treatment
- Shop / category filters / sorting
- Product detail page
- Quick view
- Search overlay
- Wishlist interactions
- Cart drawer and cart page
- Checkout and confirmation
- About
- Our Story
- Contact
- Mobile navigation and sticky mobile Add to Cart

## Important asset rule
Only real uploaded SoGlam product photos are used. Where an official product photo was not supplied, the UI deliberately displays a neutral “official photo required” placeholder rather than inventing or redesigning product packaging.

## Run
Open `index.html` in a browser. No build step is required.
